Bug #1: Incorrect maximum infection statistics

Problem:
The final outbreak summary displayed an empty city name
and -1 for the highest number of active infections.

Cause:
The comparison that updates maxInfected and mostInfectedCity
was missing from the display_summary() function.

Correction:
Added an if statement inside the city loop to compare
infection counts and update both tracking variables.

Testing:
Recompiled and ran the simulation. Verified that the
summary correctly identifies the city with the most
active infections.

Bug #2: Empty population file accepted

Problem:
The simulation continued running even when population.txt
contained no records.

Cause:
load_pop() checked whether the file opened successfully
but did not check whether any population data was loaded.

Correction:
Added a population.empty() check that returns false
when no population records are present.

Testing:
Verified that an empty population file produces an error
and prevents the simulation from starting.
